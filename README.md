# Unicorns!

js13kgames 2026
(Director's cut)

An entry to the [js13kGames 2026 competition](https://js13kgames.com/2026/) by [Frost Sun](https://github.com/Frost-Sun).

## Running

First, install dependencies with

    $ npm install

To run the game in the browser for development

    $ npm start

## Building the zip package

Install Advzip or copy advzip.exe directly into root folder.

Building the zip package:

    $ npm run build
